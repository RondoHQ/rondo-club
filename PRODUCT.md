# Rondo Club

## Platform
Web application, including mobile browsers.

## Product purpose
Help sports club volunteers manage their responsibilities in one private club environment.

## Dashboard users and outcomes
Year-group coordinators need birthdays, their assigned teams, training times and upcoming matches. Match secretaries need fixtures, pitch and dressing-room information, cancellations and their own tasks. People with both roles see one combined dashboard without duplicate entries. Existing operational roles retain their current dashboard tools.

## Constraints
Dashboard access grants no additional person, financial or team-record access. Every block and count respects its own server-side permissions. Birthdays remain a dashboard block, with no separate navigation item. Roles combine automatically. Unknown or stale fixture data must be labelled, not presented as missing assignments.

## Confirmed direction
The three interactive dashboard proposals approved in the task define the layout: tasks and relevant cancellations, prominent birthdays for coordinators, followed by fixtures and scoped teams/training. Dutch interface; existing Rondo typography, cyan accents and light/dark themes. Illustrative prototype data must be replaced with actual API data.
