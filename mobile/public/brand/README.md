# Rondo website assets

The SVG logo and wordmark and Figtree 600/700/800 WOFF2 files are unmodified copies from
`RondoHQ/website/public/` (`fonts/` for the fonts), as used by the website header and global styles.
Figtree's upstream OFL license is included alongside the files.

Native PNGs are rendered from this `rondo-logo.svg` on #F7FBFF, without editing its paths:
iOS app icon 1024px (740px mark), splash 2732px (360px mark); Android legacy icons
48dp (34dp mark), adaptive foreground 108dp (60dp mark, transparent background), and
legacy splash images retain their platform dimensions with the mark at 18% of the shortest edge.
Android assets include mdpi through xxxhdpi density scales.
