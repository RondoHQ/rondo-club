### DRY refactor — src/index.css

Before (each variant duplicated the full base @apply chain):
```css
.btn { @apply inline-flex items-center justify-center px-4 py-2 ... ; }
.btn-primary { @apply inline-flex items-center justify-center px-4 py-2 ... ; @apply bg-brand-gradient ... ; }
.btn-secondary { @apply inline-flex items-center justify-center px-4 py-2 ... ; @apply bg-transparent ... ; }
.btn-tertiary { @apply inline-flex items-center justify-center px-4 py-2 ... ; @apply bg-transparent ... ; }
.btn-danger { @apply inline-flex items-center justify-center px-4 py-2 ... ; @apply bg-red-600 ... ; }
```

After (single shared declaration via CSS selector list):
```css
.btn, .btn-primary, .btn-secondary, .btn-tertiary, .btn-danger {
  @apply inline-flex items-center justify-center px-4 py-2 rounded-lg font-medium ... ;
}
.btn-primary, .btn-secondary { @apply hover:-translate-y-0.5; }
.btn-primary { @apply bg-brand-gradient ... ; }
.btn-secondary { @apply bg-transparent ... ; }
.btn-tertiary { @apply bg-transparent ... ; }
.btn-danger { @apply bg-red-600 ... ; }
```

The hover lift is now declared only for btn-primary and btn-secondary (tiers with lift by design), so btn-tertiary and btn-danger cleanly inherit the base without needing to cancel the lift — cleaner than the original "duplicate base minus the lift" approach.
