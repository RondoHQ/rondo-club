**2. Create `src/components/AccountCard.jsx`:**

A card component for the PersonDetail second column that shows provisioning status and provides the "Maak account aan" button. **Admin-only** (guard rendering with `config.isAdmin`).

Structure:
- Import: `useState` from React, `UserPlus, Check, Loader2, AlertCircle` from `lucide-react`, `prmApi` from `@/api/client`, `useQueryClient` from `@tanstack/react-query`
- Props: `personId`, `personData` (the full person object — needs `acf.contact_info` for email check, `linked_user_id`, `welcome_email_sent_at`)
- Internal state: `provisioning` (boolean), `result` (success/error message), `error` (error string)

**Rendering logic:**

Card wrapper: `<div className="card p-6">` with `<h2 className="font-semibold text-brand-gradient mb-3">Account</h2>`

- **If `personData.linked_user_id` is truthy** (already provisioned):
  - Show a green check icon + "Account aangemaakt" message
  - Show `welcome_email_sent_at` date if available, formatted nicely: "Welkomstmail verstuurd op {date}"
  - No button (cannot re-provision, per PROV-05)

- **If no linked_user_id** (not yet provisioned):
  - Check if person has an email: iterate `personData.acf?.contact_info`, find any with `contact_type === 'email'` and non-empty `contact_value`
  - **If no email:** Show disabled button with tooltip text below: "Voeg eerst een e-mailadres toe aan deze persoon."
  - **If has email:** Show "Maak account aan" button (`UserPlus` icon) with primary styling (`btn-primary`)
  - On click: call `prmApi.provisionUser(personId)`, set `provisioning=true`
  - On success: show success message from response, invalidate `['people', 'detail', personId]` query so PersonDetail refetches with new `linked_user_id`
  - On error: show error message from `err.response?.data?.message || 'Kon account niet aanmaken'`

- **While provisioning:** Show `Loader2` spinner with "Bezig met aanmaken..." text, button disabled

**Button styling:** Use `btn-primary` class (consistent with other action buttons). Disabled state uses `opacity-50 cursor-not-allowed`.
