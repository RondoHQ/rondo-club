## Tech Debt

### CAPS-05: No In-App Manual Override UI (Deferred)
**Phase:** 206-capability-sync
**What exists:** `META_MANUAL_GRANTS` / `META_MANUAL_REVOKES` user meta keys, consumed by `sync_user()` in target formula `(mapped ∪ manual_grants) − manual_revokes`
**What's missing:** In-app UI for an admin to view/set/clear individual user's manual capability overrides
**Impact:** Admin must use WP admin user meta editor (which admins can access) or WP-CLI
**Suggested fix:** Add manual override controls to AccountCard or Gebruikers tab in a future phase

### PROF-03: Success Message May Not Render (Cosmetic)
**Phase:** 207-in-app-profile-page
**Details:** `setSuccessMessage()` is called just before `window.location.href` redirect — React may not flush the state update before the browser navigates away. Success message is cosmetic only; the actual password change and session destruction work correctly.
**Impact:** None — core functionality unaffected
