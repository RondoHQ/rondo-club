# Requirements Archive: v26.0 Discipline Case Invoicing

**Archived:** 2026-02-18
**Originally defined:** 2026-02-15

## Navigation (NAV)

- [x] **NAV-01**: Financien section appears in sidebar with Contributie, Facturen, and Instellingen sub-items
- [x] **NAV-02**: Contributie page moves from current sidebar position to under Financien

## Invoice Data Model (INV)

- [x] **INV-01**: Invoice CPT (`rondo_invoice`) stores invoice number, member link, total amount, status, payment link, PDF path
- [x] **INV-02**: Invoice numbering follows `2026T001` format (calendar year + T + zero-padded sequential number)
- [x] **INV-03**: Invoice statuses: Draft, Sent, Paid, Overdue — with due date tracking
- [x] **INV-04**: Each invoice links to one or more discipline cases as line items (ACF repeater or relationship)
- [x] **INV-05**: Overdue detection when sent invoice passes due date (configurable payment term days)

## Invoice Creation (CREATE)

- [x] **CREATE-01**: User can select one or more uninvoiced discipline cases on member's Tuchtzaken tab
- [x] **CREATE-02**: Selected cases' fees (Boete field) are summed into invoice total
- [x] **CREATE-03**: Invoice created in Draft status with case details as line items

## PDF Generation (PDF)

- [x] **PDF-01**: Invoice PDF generated using mPDF library with club logo, name, address, and contact email from settings
- [x] **PDF-02**: Invoice PDF contains member name, address, and email address
- [x] **PDF-03**: Invoice PDF lists each discipline case with match description, sanction, and fee amount
- [x] **PDF-04**: Invoice PDF shows total amount, bank account number (IBAN), and payment clause from settings
- [x] **PDF-05**: Invoice PDF includes invoice number, invoice date, and due date

## Rabobank Payment Integration (PAY)

- [x] **PAY-01**: OAuth 2.0 Premium flow with Rabobank developer portal for betaalverzoek API
- [x] **PAY-02**: System creates payment request via Rabobank API with invoice amount and description
- [x] **PAY-03**: Payment link from Rabobank stored on invoice and included in email
- [x] **PAY-04**: Rabobank API credentials (client ID, secret) stored securely in finance settings
- [x] **PAY-05**: Sandbox/production toggle for development vs live usage

## Email Delivery (EMAIL)

- [x] **EMAIL-01**: Invoice email sent via wp_mail to member's email from person contact_info
- [x] **EMAIL-02**: Email body uses configurable template with variables ({naam}, {betaallink}, {factuur_nummer}, {tuchtzaken_lijst}, {totaal_bedrag})
- [x] **EMAIL-03**: Invoice PDF attached to email

## Finance Settings (SET)

- [x] **SET-01**: Finance settings page at Financien > Instellingen
- [x] **SET-02**: Club invoice details: organization name, address (multi-line), contact email
- [x] **SET-03**: Bank account field (IBAN) and payment clause text
- [x] **SET-04**: Payment term days (default 14)
- [x] **SET-05**: Email template editor with variable placeholder documentation
- [x] **SET-06**: Rabobank API credential fields (client ID, secret, environment toggle)

## Invoice Management (MGMT)

- [x] **MGMT-01**: Facturen page lists all invoices with columns: number, member name, amount, status, date sent
- [x] **MGMT-02**: Invoice detail view with full info, PDF download, and status actions
- [x] **MGMT-03**: User can send invoice (transitions Draft -> Sent, generates PDF, creates payment link, sends email)
- [x] **MGMT-04**: User can mark invoice as Paid manually
- [x] **MGMT-05**: User can resend invoice email
- [x] **MGMT-06**: Invoice history visible on member's profile page
