  <files>includes/class-mollie-webhook.php</files>
  <action>
Create `includes/class-mollie-webhook.php` in the `Rondo\Finance` namespace.

**Class structure:**

Constructor registers `rest_api_init` hook to `register_routes()`.

`register_routes()` — Register a single POST route:
- Namespace: `rondo/v1`
- Route: `/mollie/webhook`
- Method: `WP_REST_Server::CREATABLE`
- Callback: `handle_webhook`
- Permission callback: `'__return_true'` (public endpoint — Mollie has no WordPress auth)

`handle_webhook( WP_REST_Request $request )` — The webhook handler:
1. Extract payment ID: `sanitize_text_field( $request->get_param( 'id' ) )`
2. If empty payment ID: `error_log( 'Mollie webhook: missing payment ID' )` and return `rest_ensure_response( [ 'ok' => true ] )`
3. Re-fetch payment from Mollie API (WHKT-02 — never trust POST body alone):
   - `$mollie_client = new MollieClient()`
   - `$payment = $mollie_client->get()->payments->get( $payment_id )`
   - Catch `\Mollie\Api\Exceptions\ApiException` — log message and return 200
4. If `! $payment->isPaid()`: return 200 (nothing to do). Use `isPaid()` NOT `$payment->status === 'paid'` — isPaid() checks `paidAt` which is more reliable.
5. Find invoice by `_mollie_payment_id` meta:
   ```php
   $query = new \WP_Query( [
       'post_type'      => 'rondo_invoice',
       'post_status'    => 'any',
       'posts_per_page' => 1,
       'meta_query'     => [
           [
               'key'   => '_mollie_payment_id',
               'value' => $payment_id,
           ],
       ],
   ] );
   ```
   Note: `post_status => 'any'` is required because invoice statuses (`rondo_sent`, `rondo_overdue`) are custom and not in the default query.
6. If no invoice found: `error_log( 'Mollie webhook: no invoice found for payment ' . $payment_id )` and return 200
7. Idempotency check (WHKT-04): if `$invoice->post_status === 'rondo_paid'`, return 200 (already paid, no-op)
8. Transition to paid:
   - `wp_update_post( [ 'ID' => $invoice->ID, 'post_status' => 'rondo_paid' ] )`
   - `update_field( 'status', 'paid', $invoice->ID )` — Use `status` field NOT `payment_status` (the ACF field is named `status` per acf-json/group_invoice_fields.json and RestInvoices pattern)
9. Return `rest_ensure_response( [ 'ok' => true ] )`

**Critical: Every code path returns HTTP 200** (WHKT-05). Mollie retries on non-200 responses which would cause retry storms.
