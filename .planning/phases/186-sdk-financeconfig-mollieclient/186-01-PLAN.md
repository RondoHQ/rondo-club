Edit `includes/class-finance-config.php` — do NOT rewrite the file, only ADD to it:

a) Add 2 new constants after `OPTION_BCC_EMAIL` (line 37):
```php
const OPTION_MOLLIE_API_KEY          = 'rondo_finance_mollie_api_key';
const OPTION_ACTIVE_PAYMENT_PROVIDER = 'rondo_finance_active_payment_provider';
```

b) Add 4 new public methods and 1 private helper method after `update_rabobank_credentials()` (after line 334):

- `get_mollie_api_key(): string` — reads encrypted option via `get_option(self::OPTION_MOLLIE_API_KEY, '')`, returns empty string if not set, otherwise decrypts with `CredentialEncryption::decrypt($encrypted)` and returns `$data['api_key'] ?? ''`. Note: CredentialEncryption is already imported at the top of the file.

- `update_mollie_api_key(string $api_key): bool` — if empty, calls `delete_option(self::OPTION_MOLLIE_API_KEY)` and returns the bool result. Otherwise encrypts `['api_key' => $api_key]` with `CredentialEncryption::encrypt()` and stores via `update_option()`.

- `get_active_payment_provider(): string` — returns `get_option(self::OPTION_ACTIVE_PAYMENT_PROVIDER, 'rabobank')`. Default MUST be `'rabobank'` so existing behavior is unchanged.

- `update_active_payment_provider(string $provider): bool` — validates against `['rabobank', 'mollie']` allowlist using `in_array($provider, $allowed, true)`. Returns false for invalid providers. Stores via `update_option()`.

- `private derive_mollie_environment(string $api_key): string` — returns `''` if empty, `'live'` if `str_starts_with($api_key, 'live_')`, otherwise `'test'`. Safe to use `str_starts_with()` because PHP >=8.0 is required.

c) Extend `get_all_settings()` return array — add 3 new keys after `'rabobank_environment'` (line 205):

Before the return array, add: `$mollie_api_key = $this->get_mollie_api_key();`

Then add these keys to the return array:
```php
'mollie_has_api_key'      => ! empty( $mollie_api_key ),
'mollie_environment'      => $this->derive_mollie_environment( $mollie_api_key ),
'active_payment_provider' => $this->get_active_payment_provider(),
```

CRITICAL: Do NOT add `'mollie_api_key'` to the return array. The raw key must NEVER be exposed via the settings REST endpoint.

d) Extend `update_settings()` — add 2 new `isset()` blocks after the Rabobank credentials handler (after line 312, before `return $success`):

```php

    $success = $this->update_mollie_api_key(
        sanitize_text_field( $data['mollie_api_key'] )

if ( isset( $data['active_payment_provider'] ) ) {
    $success = $this->update_active_payment_provider(
        sanitize_text_field( $data['active_payment_provider'] )
    ) && $success;
}
```

Follow the existing code style: tabs for indentation, WordPress PHP doc block format for each method, consistent spacing.

Create new file `includes/class-mollie-client.php` with namespace `Rondo\Finance`.

The class is a thin wrapper around `Mollie\Api\MollieApiClient`. It is NOT a singleton — each instantiation reads a fresh API key from FinanceConfig.

File structure:
```php
<?php
/**
 * Mollie Client Wrapper
 *
 * Initialises the Mollie PHP SDK with the stored API key, providing
 * a configured MollieApiClient to MolliePayment and MollieWebhook.
 *
 * @package Rondo\Finance
 */

namespace Rondo\Finance;

use Mollie\Api\MollieApiClient;
use Rondo\Config\FinanceConfig;

if ( ! defined( 'ABSPATH' ) ) {
    exit;
}
```

Class `MollieClient`:
- Private property `MollieApiClient $client`
- Constructor: creates `new FinanceConfig()`, calls `$config->get_mollie_api_key()`, creates `new MollieApiClient()`, calls `$this->client->setApiKey($api_key)`. Throws `\Mollie\Api\Exceptions\ApiException` if key is invalid (document in @throws PHPDoc).
- Public method `get(): MollieApiClient` — returns `$this->client`.

Use tabs for indentation (matching project convention). Include full WordPress-style PHPDoc blocks on the class and each method.
