**Helper function:** Create a private helper method in `class-rest-api.php` (or a shared utility) that builds the backward-compatible contact_info array from fixed fields:

```php
private function build_contact_info_from_fixed_fields( int $post_id ): array {
    $contacts = [];
    $field_map = [
        'email_1'      => 'email',
        'email_2'      => 'email2',
        'mobile_1'     => 'mobile',
        'mobile_2'     => 'mobile',
        'telephone_1'  => 'phone',
        'telephone_2'  => 'phone',
    ];
    foreach ( $field_map as $acf_field => $contact_type ) {
        $value = get_field( $acf_field, $post_id );
        if ( ! empty( $value ) ) {
            $contacts[] = [
                'contact_type'  => $contact_type,
                'contact_value' => $value,
                'contact_label' => '',
            ];
        }
    }
    return $contacts;
}
```

Include this `contact_info` array in the REST API person response so the frontend continues working unchanged.
