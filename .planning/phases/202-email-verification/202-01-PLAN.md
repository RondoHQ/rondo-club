**Fix 1 -- EmailChannel (`includes/class-email-channel.php` line 288-291):**

Replace the `set_email_from_address` method body. Instead of using `parse_url( home_url(), PHP_URL_HOST )` which returns `rondo.svawc.nl`, extract the root domain (last 2 parts of the hostname):

```php
public function set_email_from_address( $from_email ) {
    $host  = wp_parse_url( home_url(), PHP_URL_HOST );
    $parts = explode( '.', $host );
    $domain = count( $parts ) >= 2
        ? implode( '.', array_slice( $parts, -2 ) )
        : $host;
    return 'notifications@' . $domain;
}
```

This extracts `svawc.nl` from `rondo.svawc.nl`. Uses `wp_parse_url` (WordPress wrapper) instead of `parse_url`.

**Fix 2 -- MentionNotifications (`includes/class-mention-notifications.php` lines 88-93):**

Add a `From:` header to the `wp_mail()` call in `send_immediate_notification()`. Currently the headers array only has `Content-Type`. Add an explicit From header using the same root-domain extraction logic:

```php
$host  = wp_parse_url( home_url(), PHP_URL_HOST );
$parts = explode( '.', $host );
$domain = count( $parts ) >= 2

$site_name = get_bloginfo( 'name' );

        'Content-Type: text/html; charset=UTF-8',

```

Add the domain extraction code just before the `wp_mail()` call (after the `$message` sprintf on line 80-86, before the `wp_mail` on line 88).

**DRY note:** Both files use the same root-domain extraction. Since this is only 3 lines in 2 files, the duplication is acceptable -- extracting to a shared helper would be over-engineering for a 2-occurrence pattern. If a third email sender needs this, refactor then.
