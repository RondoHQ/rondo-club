This tests the FROM-address fix from plan 202-01. The fixed `MentionNotifications` class now sends with `notifications@svawc.nl`:

```bash
source .env && ssh -p "$DEPLOY_SSH_PORT" "$DEPLOY_SSH_USER@$DEPLOY_SSH_HOST" "cd $DEPLOY_REMOTE_WP_PATH && wp eval '
\$site_name = get_bloginfo(\"name\");
\$host  = wp_parse_url( home_url(), PHP_URL_HOST );
\$parts = explode( \".\", \$host );
\$domain = count( \$parts ) >= 2
    ? implode( \".\", array_slice( \$parts, -2 ) )
    : \$host;

    \"joost@joost.blog\",

'"
```
