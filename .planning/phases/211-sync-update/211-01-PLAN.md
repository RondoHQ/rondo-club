   `normalizePhone(value)` — Port the PHP PhoneNormalizer logic to JavaScript:
   - Strip Unicode invisible characters (zero-width spaces, BOM, directional marks)
   - Trim whitespace; return empty string if empty
   - If starts with `+`: keep `+`, strip non-digits from rest, return
   - If starts with `00`: strip the leading `00`, strip non-digits, prepend `+`, return
   - If starts with `0`: strip the leading `0`, strip non-digits, prepend `+31`, return
   - Edge case: digits only without leading 0 or + — strip non-digits, return as-is

   `e164ToLocal(value)` — Convert E.164 back to Dutch local format for Sportlink:
   - If null/empty, return empty string
   - If starts with `+31`: strip `+31`, prepend `0`, return (e.g., `+31612345678` -> `0612345678`)
   - Otherwise return as-is (non-Dutch numbers stay international)
