  <action>
Create `includes/class-user-provisioning.php` in namespace `Rondo\Users`.

**Class structure:**

Constants for WordPress options (follow VOGEmail pattern):
- `OPTION_EMAIL_SUBJECT` = `'rondo_welcome_email_subject'`
- `OPTION_EMAIL_BODY` = `'rondo_welcome_email_body'`
- `OPTION_FROM_EMAIL` = `'rondo_welcome_from_email'`
- `OPTION_FROM_NAME` = `'rondo_welcome_from_name'`

Constants for meta keys:
- `META_USER_ID` = `'_rondo_wp_user_id'` (on person post)
- `META_EMAIL_SENT` = `'_welcome_email_sent_at'` (on person post)
- `META_KNVB_ID` = `'_rondo_knvb_id'` (on user)

**Methods:**

1. `public function provision( int $person_id ): array|\WP_Error`
   - Validate person exists and is published
   - **Idempotency check (PROV-05):** Check `_rondo_wp_user_id` post meta — if set and the user exists, return `['status' => 'already_exists', 'user_id' => $existing_id, 'message' => 'Gebruiker bestaat al.']`
   - Get person email from `contact_info` ACF field (iterate array, find `contact_type === 'email'`, take first `contact_value`). If no email found, return `WP_Error('no_email', 'Deze persoon heeft geen e-mailadres.')`
   - Check `email_exists()` — if email is taken by a different user, return `WP_Error('email_taken', 'Dit e-mailadres is al in gebruik door een andere gebruiker.')`
   - Generate username: `generate_username( first_name, last_name )` — sanitize_user(strtolower(first.last)), increment suffix if taken
   - Create user: `wp_create_user( $login, wp_generate_password( 24, true, true ), $email )`
   - Set base role: `$user->set_role( \Rondo\Core\UserRoles::ROLE_NAME )`
   - **Assign roles from Functies (Phase 204 integration):** Iterate `get_field('work_history', $person_id)`, collect unique `job_title` values, call `\Rondo\Config\FunctieCapabilityMap::get_roles_for_functie()` for each, `$user->add_role()` for each mapped role
   - **Bidirectional link (PROV-03):** Set `update_user_meta($user_id, 'rondo_linked_person_id', $person_id)` AND `update_post_meta($person_id, self::META_USER_ID, $user_id)`
   - **KNVB ID (PROV-04):** `$knvb_id = get_field('knvb-id', $person_id); if ($knvb_id) update_user_meta($user_id, self::META_KNVB_ID, $knvb_id);`
   - **Set display name:** `wp_update_user(['ID' => $user_id, 'display_name' => trim($first_name . ' ' . $last_name)])` so the user list shows a real name
   - Generate password reset key with scoped 7-day expiry: add `password_reset_expiration` filter before calling `get_password_reset_key()`, remove filter after. The filter returns `7 * DAY_IN_SECONDS`.
   - If reset key is WP_Error, rollback (delete user + remove meta) and return the error
   - Call `send_welcome_email()` — if it fails, still return success (user created, email failed — log the issue but don't rollback the user)
   - Return `['status' => 'created', 'user_id' => $user_id, 'message' => 'Account aangemaakt en welkomstmail verstuurd.']`

2. `private function send_welcome_email( int $person_id, int $user_id, string $reset_key ): true|\WP_Error`
   - Build password-set URL using `add_query_arg(['action' => 'rp', 'key' => $reset_key, 'login' => rawurlencode($user->user_login)], network_site_url('wp-login.php', 'login'))`
   - Get subject and body from options (with defaults)
   - Perform `{variable}` substitution on both subject and body:
     - `{first_name}` — person first name from ACF
     - `{email}` — user email
     - `{login}` — WP username
     - `{set_password_url}` — the generated URL
     - `{club_naam}` — `\Rondo\Config\ClubConfig::get_club_name()` with fallback to `get_bloginfo('name')`
   - Send via `wp_mail()` with custom from address using add/remove filter pattern (exact VOGEmail pattern)
   - Headers: `['Content-Type: text/html; charset=UTF-8']`
   - Body: `nl2br( esc_html( $body ) )`
   - On success: set `update_post_meta($person_id, self::META_EMAIL_SENT, current_time('Y-m-d H:i:s'))`
   - Log to timeline: `(new \Rondo\Collaboration\CommentTypes())->create_email_log($person_id, ['template_type' => 'welcome', 'recipient' => $email, 'subject' => $subject, 'content' => nl2br(esc_html($body))])`
   - On failure: return `WP_Error('send_failed', 'Welkomstmail kon niet verstuurd worden.')`

3. `private function generate_username( string $first, string $last ): string`
   - `$base = sanitize_user( strtolower( $first . '.' . $last ), true )`
   - If empty, use `'gebruiker-' . uniqid()` as fallback
   - Increment suffix (`$base1`, `$base2`, ...) while `username_exists($login)`

4. `public function get_settings(): array` — Returns array with `subject`, `body`, `from_email`, `from_name` from options (with defaults)

5. `public function update_settings( array $settings ): array`
   - Sanitize and save each provided field to its option
   - Return the updated settings array

6. `public function get_default_subject(): string` — Returns `'Welkom bij {club_naam}'`

7. `public function get_default_body(): string` — Returns the Dutch default template from research:
   ```
   Beste {first_name},

   Je hebt een account gekregen voor {club_naam}.

   Gebruik de volgende link om je wachtwoord in te stellen en in te loggen:
   {set_password_url}

   Je gebruikersnaam is: {login}

   Deze link is 7 dagen geldig.

   Met sportieve groet,
   {club_naam}
   ```

8. `public function filter_mail_from( $from_email ): string` and `public function filter_mail_from_name( $from_name ): string` — VOGEmail pattern, return configured from address/name or passthrough

9. Private helper: `private function get_person_email( int $person_id ): ?string` — Iterates `contact_info` ACF field, finds first `contact_type === 'email'`, returns `contact_value` or null.

**Important anti-patterns to avoid:**
- Do NOT call `wp_new_user_notification()` — it sends WordPress default emails
- Do NOT use `wp_set_password()` — use `get_password_reset_key()` instead
- Do NOT change `post_author` on the person post
