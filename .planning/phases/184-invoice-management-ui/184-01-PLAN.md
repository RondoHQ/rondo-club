1. **src/hooks/useInvoices.js** — Add hooks below the existing ones:

   a. `useInvoices(params, options)` — List all invoices:
      - queryKey: `['invoices', params]`
      - queryFn: `prmApi.getInvoices(params)` returning `response.data`
      - staleTime: 30000 (30s, consistent with existing invoice hooks)
      - enabled: `options.enabled ?? true`

   b. `useInvoice(id, options)` — Get single invoice detail:
      - queryKey: `['invoice', id]`
      - queryFn: `prmApi.getInvoice(id)` returning `response.data`
      - enabled: `!!id && (options.enabled ?? true)`
      - staleTime: 30000

   c. `useSendInvoice()` — Send draft invoice mutation:
      - mutationFn: `prmApi.sendInvoice(id)` returning `response.data`
      - onSuccess: invalidate `['invoices']`, `['invoice']`, `['invoices', 'person']`

   d. `useUpdateInvoiceStatus()` — Update invoice status mutation:
      - mutationFn: accepts `{ id, status }`, calls `prmApi.updateInvoiceStatus(id, status)` returning `response.data`
      - onSuccess: invalidate `['invoices']`, `['invoice']`, `['invoices', 'person']`

   e. `useResendInvoice()` — Resend invoice email mutation:
      - mutationFn: `prmApi.resendInvoice(id)` returning `response.data`
