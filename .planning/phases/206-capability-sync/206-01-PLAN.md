  <name>Task 1: Create CapabilitySync service class with grant/revoke reconciliation and manual override tracking</name>
  <files>includes/class-capability-sync.php</files>
  <action>
Create `includes/class-capability-sync.php` in the `Rondo\Users` namespace. Follow the exact pattern of `UserProvisioning` — pure service class, no constructor, no hooks, PSR-4 autoloaded.

**Constants:**
- `META_MANUAL_GRANTS` = `'_rondo_cap_manual_grants'` — JSON-encoded array of role slugs admin has manually granted
- `META_MANUAL_REVOKES` = `'_rondo_cap_manual_revokes'` — JSON-encoded array of role slugs admin has manually revoked

**Method `sync_user( int $user_id, array $functies ): array|\WP_Error`:**

1. Load `$user = new \WP_User( $user_id )`. Return WP_Error if user doesn't exist.
2. **Administrator guard** (CAPS-07): `if ( in_array( 'administrator', $user->roles, true ) )` → return `[ 'status' => 'skipped', 'reason' => 'administrator' ]`.
3. Compute syncable roles: `array_diff( \Rondo\Core\UserRoles::get_role_slugs(), [ 'rondo_user' ] )` — this gives `['rondo_fairplay', 'rondo_vog', 'rondo_bestuur']`. Never touch `rondo_user`.
4. For each functie in `$functies`, call `\Rondo\Config\FunctieCapabilityMap::get_roles_for_functie( $functie )` and collect unique roles filtered to syncable_roles → `$mapped_roles`.
5. Read manual overrides from user meta:
   - `$manual_grants = (array) json_decode( get_user_meta( $user_id, self::META_MANUAL_GRANTS, true ) ?: '[]', true )`
   - `$manual_revokes = (array) json_decode( get_user_meta( $user_id, self::META_MANUAL_REVOKES, true ) ?: '[]', true )`
6. Compute target roles: `$target_roles = array_diff( array_unique( array_merge( $mapped_roles, $manual_grants ) ), $manual_revokes )`
7. Filter target roles to only syncable roles (safety net).
8. Get current user's syncable roles: `$current_roles = array_values( array_intersect( (array) $user->roles, $syncable_roles ) )`
9. Compute diff:
   - `$to_grant = array_diff( $target_roles, $current_roles )`
   - `$to_revoke = array_diff( $current_roles, $target_roles )`
10. Apply changes: `$user->add_role()` for each to_grant, `$user->remove_role()` for each to_revoke.
    **CRITICAL:** Use `add_role()` and `remove_role()`, NEVER `set_role()` which wipes all roles.
11. Return `[ 'status' => 'synced', 'user_id' => $user_id, 'granted' => array_values($to_grant), 'revoked' => array_values($to_revoke), 'current_roles' => array_values(array_intersect((array)(new \WP_User($user_id))->roles, $syncable_roles)) ]`.

**Method `sync_all( array $knvb_functies_map = [] ): array`:**

1. Get all provisioned users: `get_users(['meta_key' => \Rondo\Users\UserProvisioning::META_KNVB_ID, 'meta_compare' => '!=', 'meta_value' => '', 'number' => -1])`.
2. If `$knvb_functies_map` is empty, derive functies from person work_history ACF for each user:
   - Get `rondo_linked_person_id` user meta → person post ID.
   - Read `work_history` ACF field from person. Filter entries where `is_current` is truthy.
   - Collect `job_title` values as functies.
3. For each user, get their KNVB ID from user meta, look up functies from the map, call `$this->sync_user()`.
4. Aggregate results: `[ 'total' => count, 'synced' => count, 'skipped' => count, 'errors' => [], 'details' => [] ]`.
5. Each detail entry includes user_id, knvb_id, and the sync_user result.

**Method `sync_user_by_knvb_id( string $knvb_id, array $functies ): array|\WP_Error`:**

1. Look up WP user by KNVB ID: `get_users(['meta_key' => \Rondo\Users\UserProvisioning::META_KNVB_ID, 'meta_value' => $knvb_id, 'number' => 1])`.
2. If no user found, return `[ 'status' => 'no_user', 'knvb_id' => $knvb_id ]` (not an error — HTTP 200).
3. If user found, call `$this->sync_user( $users[0]->ID, $functies )`.

Include proper PHPDoc, namespace declaration, ABSPATH check. Follow exact code style from `class-user-provisioning.php`.

<task type="auto">
  <name>Task 2: Register capability-sync REST endpoints in class-rest-api.php</name>
  <files>includes/class-rest-api.php</files>
  <action>
Add two REST route registrations to the `register_routes()` method of `class-rest-api.php`, immediately after the existing provisioning routes (after the `/provisioning/settings` block).

**Route 1: Per-user capability sync**
```php
// Capability sync (admin only — called by rondo-sync per member)
register_rest_route(
    'rondo/v1',
    '/capability-sync',
    [
        'methods'             => \WP_REST_Server::CREATABLE,
        'callback'            => [ $this, 'sync_user_capabilities' ],
        'permission_callback' => [ $this, 'check_admin_permission' ],
        'args'                => [
            'knvb_id' => [
                'required'          => true,
                'validate_callback' => function ( $param ) {
                    return is_string( $param ) && ! empty( $param );
                },
            ],
            'functies' => [
                'required'          => true,
                'validate_callback' => function ( $param ) {
                    return is_array( $param );
                },
            ],
        ],
    ]
);
```

**Route 2: Sync all capabilities (body-less — derives functies from person ACF)**
```php
// Capability sync all (admin only — on-demand from Settings)
register_rest_route(
    'rondo/v1',
    '/capability-sync/all',
    [
        'methods'             => \WP_REST_Server::CREATABLE,
        'callback'            => [ $this, 'sync_all_capabilities' ],
        'permission_callback' => [ $this, 'check_admin_permission' ],
    ]
);
```

**Callback `sync_user_capabilities( $request )`:**
1. Get `knvb_id` and `functies` from request params.
2. Sanitize: `$knvb_id = sanitize_text_field( $request->get_param( 'knvb_id' ) )`.
3. `$functies = array_map( 'sanitize_text_field', (array) $request->get_param( 'functies' ) )`.
4. Instantiate `$sync = new \Rondo\Users\CapabilitySync()`.
5. Call `$result = $sync->sync_user_by_knvb_id( $knvb_id, $functies )`.
6. If `is_wp_error($result)` return it, otherwise `rest_ensure_response($result)`.

**Callback `sync_all_capabilities( $request )`:**
1. Instantiate `$sync = new \Rondo\Users\CapabilitySync()`.
2. Call `$result = $sync->sync_all()` (no args — server derives functies from ACF).
3. Return `rest_ensure_response($result)`.
