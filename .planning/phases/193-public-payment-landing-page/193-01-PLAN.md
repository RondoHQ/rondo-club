**Class structure:**

```
class PublicPaymentPage {
    const TOKEN_META_KEY = '_payment_token';
    const TOKEN_LENGTH   = 32; // bytes → 64 hex chars

    public function __construct()
    public function register_rewrite_rules()
    public function add_query_vars( $vars )
    public function handle_request()
    public static function generate_token( int $invoice_id ): string
    public static function get_invoice_by_token( string $token ): ?int
    private function render_page( int $invoice_id, string $token )
    private function render_success_page( int $invoice_id )
    private function render_error( string $message )
    private function handle_plan_selection( int $invoice_id, string $token )
    private function write_installment_meta( int $invoice_id, int $count, float $total, float $admin_fee )
    private function create_installment_payment( int $invoice_id, float $amount, int $installment_number, string $token )
    private function render_html_header( string $title )
    private function render_html_footer()
    private function format_currency( float $amount ): string
}
```

**Constructor** — Register 3 hooks:
- `add_action( 'init', [ $this, 'register_rewrite_rules' ] );`
- `add_filter( 'query_vars', [ $this, 'add_query_vars' ] );`
- `add_action( 'template_redirect', [ $this, 'handle_request' ], 0 );`
Priority 0 fires before SPA catch-all at priority 1 (same pattern as CardDAVServer).

**register_rewrite_rules()** — Single rule:
```php
add_rewrite_rule( '^betaling/([a-f0-9]{64})$', 'index.php?rondo_payment_token=$matches[1]', 'top' );
```
Regex enforces exactly 64 hex chars (32 bytes hex-encoded).

**add_query_vars()** — Add `rondo_payment_token` to WordPress query vars.

**handle_request()** — Main dispatcher:
1. Read `get_query_var( 'rondo_payment_token' )`. If empty, `return` (not our request).
2. Sanitize token: `sanitize_key()` — this lowercases and strips non-alphanum.
3. Look up invoice: `self::get_invoice_by_token( $token )`. If null → `render_error( 'Betaallink niet gevonden of verlopen.' )` + `exit`.
4. Check if `?betaald=1` query param is present → call `render_success_page( $invoice_id )` + `exit`.
5. If `$_SERVER['REQUEST_METHOD'] === 'POST'` → call `handle_plan_selection( $invoice_id, $token )` (this method handles its own exit/render).
6. Otherwise → call `render_page( $invoice_id, $token )` + `exit`.
Always `exit` after rendering — never `return` (prevents SPA catch-all from firing).

**generate_token( $invoice_id )** — Static method:
1. `$token = bin2hex( random_bytes( self::TOKEN_LENGTH ) );`
2. `update_post_meta( $invoice_id, self::TOKEN_META_KEY, $token );`
3. Return `$token`.
Same pattern as `ICalFeed::generate_token()`.

**get_invoice_by_token( $token )** — Static method:
```php
$posts = get_posts([
    'post_type'      => 'rondo_invoice',
    'post_status'    => 'any',
    'posts_per_page' => 1,
    'fields'         => 'ids',
    'meta_query'     => [[
        'key'   => self::TOKEN_META_KEY,
        'value' => $token,
    ]],
]);
return $posts[0] ?? null;
```

**render_page( $invoice_id, $token )** — GET handler:
1. Read invoice data:
   - `$invoice_number = get_field( 'invoice_number', $invoice_id );`
   - `$total_amount = (float) get_field( 'total_amount', $invoice_id );`
   - `$person_id = get_field( 'person', $invoice_id );` (returns post ID)
   - `$person_name = get_the_title( $person_id );`
   - Season: there is NO `season` ACF field on invoices. Derive season from the invoice creation date using `MembershipFees::get_season_key()`:
     ```php
     $membership_fees = new \Rondo\Fees\MembershipFees();
     $invoice_date = get_the_date( 'Y-m-d', $invoice_id );
     $season = $membership_fees->get_season_key( $invoice_date );
     ```
     This returns a string like `"2025-2026"` based on the July 1 season boundary.
2. Read admin fee: `$config = new FinanceConfig(); $admin_fee = $config->get_installment_admin_fee();`
3. Calculate per-plan amounts:
   - Full: `$total_amount` (no admin fee)
   - 3 installments: each `round( $total_amount / 3, 2 ) + $admin_fee`
   - 8 installments: each `round( $total_amount / 8, 2 ) + $admin_fee`
4. Output `status_header( 200 ); nocache_headers(); header( 'Content-Type: text/html; charset=UTF-8' );`
5. Render standalone HTML page with inline CSS (NO external dependencies, NO wp_head):
   - Rondo branding: use club name from `get_bloginfo('name')`
   - Invoice summary card: member name, invoice number, season, total amount
   - Three plan selection forms (each a separate `<form method="POST">`):

     - "Volledig betalen" — shows `$total_amount`, single submit button
     - "3 termijnen" — shows per-installment amount including admin fee, total with fees
     - "8 termijnen" — shows per-installment amount including admin fee, total with fees
   - Admin fee explanation text below multi-installment options: "Per termijn wordt {admin_fee} administratiekosten in rekening gebracht."
   - If admin_fee is 0.00, hide the admin fee line and just show base installment amounts.

**handle_plan_selection( $invoice_id, $token )** — POST handler:
1. CSRF check: `$submitted_token = sanitize_key( $_POST['token'] ?? '' );` — if `$submitted_token !== $token`, call `render_error( 'Ongeldige aanvraag.' )` and return.
2. Read and validate plan: `$plan = sanitize_key( $_POST['plan'] ?? '' );` — allowed values: `[ 'full', 'quarterly_3', 'monthly_8' ]`. If invalid, `render_error( 'Ongeldige keuze.' )` and return.
3. **Idempotency check:** If `get_post_meta( $invoice_id, '_installment_1_mollie_payment_id', true )` is not empty, check if a checkout URL exists at `_installment_1_payment_link`. If yes, redirect to it with `wp_redirect()` + `exit`. This prevents double Mollie payments on browser back-button.
4. Read amounts: `$total = (float) get_field( 'total_amount', $invoice_id );`, `$config = new FinanceConfig(); $admin_fee = $config->get_installment_admin_fee();`
5. Store plan meta:
   - `update_post_meta( $invoice_id, '_installment_plan', $plan );`
   - For `full`: `update_post_meta( $invoice_id, '_installment_count', 1 );` — first_amount = $total (no admin fee).
   - For `quarterly_3`: `update_post_meta( $invoice_id, '_installment_count', 3 );` — first_amount = `round( $total / 3, 2 ) + $admin_fee`. Call `write_installment_meta( $invoice_id, 3, $total, $admin_fee )`.
   - For `monthly_8`: `update_post_meta( $invoice_id, '_installment_count', 8 );` — first_amount = `round( $total / 8, 2 ) + $admin_fee`. Call `write_installment_meta( $invoice_id, 8, $total, $admin_fee )`.
6. Create Mollie payment: `$checkout_url = $this->create_installment_payment( $invoice_id, $first_amount, 1, $token );`
7. If `is_wp_error( $checkout_url )` → `render_error( 'Betaling aanmaken mislukt. Probeer het later opnieuw.' )` and return.
8. `wp_redirect( $checkout_url ); exit;`

**write_installment_meta( $invoice_id, $count, $total, $admin_fee )** — Write flat meta per installment:
For each installment N (1 to $count):
- `_installment_N_amount` = `round( $total / $count, 2 )`
- `_installment_N_admin_fee` = `$admin_fee` (same for each installment)
- `_installment_N_status` = `'pending'`
- Leave `_installment_N_due_date`, `_installment_N_sent_at`, `_installment_N_paid_at`, `_installment_N_mollie_payment_id`, `_installment_N_payment_link` unset (Phase 195 populates due dates, Phase 194 writes payment IDs for 2-N).
Handle rounding remainder: add/subtract difference on last installment so installment amounts sum exactly to total.

**create_installment_payment( $invoice_id, $amount, $installment_number, $token )** — Mollie payment:
1. Guard: check `$config->get_mollie_api_key()` is not empty. If empty, return `WP_Error`.
2. Build Mollie payment payload:
   ```php
   $invoice_number = get_field( 'invoice_number', $invoice_id );
   $plan = get_post_meta( $invoice_id, '_installment_plan', true );
   $count = (int) get_post_meta( $invoice_id, '_installment_count', true );

   // Description varies by plan type
   if ( $plan === 'full' ) {
       $description = 'Factuur ' . $invoice_number;
   } else {
       $description = 'Termijn ' . $installment_number . '/' . $count . ' - Factuur ' . $invoice_number;
   }

   $payload = [
       'amount' => [
           'currency' => 'EUR',
           'value'    => number_format( $amount, 2, '.', '' ),
       ],
       'description' => $description,
       'redirectUrl' => home_url( '/betaling/' . $token . '?betaald=1' ),
       'metadata'    => [
           'invoice_id'         => $invoice_id,
           'installment_number' => $installment_number,
       ],
   ];
   ```
3. Conditionally add `webhookUrl` — omit on localhost/.local (same pattern as `MolliePayment::create_payment_link()`):
   ```php
   $site_url = get_site_url();
   if ( false === strpos( $site_url, 'localhost' ) && false === strpos( $site_url, '.local' ) ) {
       $payload['webhookUrl'] = rest_url( 'rondo/v1/mollie/webhook' );
   }
   ```
4. Try/catch Mollie API call:
   ```php
   try {
       $mollie_client = new MollieClient();
       $mollie = $mollie_client->get();
       $payment = $mollie->payments->create( $payload );
   } catch ( \Mollie\Api\Exceptions\ApiException $e ) {
       error_log( 'Mollie API exception (installment): ' . $e->getMessage() );
       return new \WP_Error( 'mollie_api_error', $e->getMessage() );
   }
   ```
5. Store results on invoice:
   - `update_post_meta( $invoice_id, '_installment_' . $installment_number . '_mollie_payment_id', $payment->id );`
   - `update_post_meta( $invoice_id, '_installment_' . $installment_number . '_payment_link', $payment->getCheckoutUrl() );`
   - Reverse-lookup: `update_post_meta( $invoice_id, '_mollie_pid_' . $payment->id, $installment_number );`
6. Return `$payment->getCheckoutUrl()`.
