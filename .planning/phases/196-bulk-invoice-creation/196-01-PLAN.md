**Create `includes/class-bulk-invoice-creator.php`** in namespace `Rondo\Finance`:

1. Constants: `CRON_HOOK = 'rondo_bulk_invoice_batch'`, `JOB_OPTION = 'rondo_bulk_invoice_job'`, `BATCH_SIZE = 50`.

2. Constructor: register `add_action( self::CRON_HOOK, [ $this, 'run_batch' ] )`.

3. `public static function start_job( string $season ): array` — static method called by REST endpoint:
   - Check existing job via `get_option( self::JOB_OPTION, [] )`. If status is `'running'`, throw or return error.
   - Query all published person IDs with `suppress_filters => true`, `fields => 'ids'`, `posts_per_page => -1`, `no_found_rows => true`.
   - Build job state array: `season`, `status => 'running'`, `total`, `offset => 0`, `created => 0`, `skipped => 0`, `errors => 0`, `started_at => current_time('Y-m-d H:i:s')`, `finished_at => null`, `person_ids` (array of int IDs).
   - Save with `update_option( self::JOB_OPTION, $state, false )` (autoload=no).
   - Schedule first batch: `wp_schedule_single_event( time() + 2, self::CRON_HOOK )`.
   - Return `$state` (without person_ids for response).

4. `public function run_batch(): void` — cron callback:
   - Read job state from option. If empty or status !== 'running', return.
   - Slice `person_ids` at `offset` for `BATCH_SIZE`.
   - For each person_id, call `$this->create_membership_invoice( $person_id, $state['season'] )` — returns 'created', 'skipped', or 'error'. Increment counters.
   - Update offset. If offset >= total, set status='done' and finished_at. Otherwise, `wp_schedule_single_event( time() + 2, self::CRON_HOOK )`.
   - Save state with `update_option( self::JOB_OPTION, $state, false )`.

5. `private function create_membership_invoice( int $person_id, string $season ): string`:
   - Get fee via `$fees->get_fee_for_person_cached( $person_id, $season )`. If null, return 'skipped'.
   - Check former member eligibility: if former and not in season, return 'skipped'. Use the same logic as `get_fee_list()` in class-rest-api.php (check `former_member` meta, then `lid-sinds` against season end).
   - Check fee amount: if `$fee_data['final_fee'] <= 0`, return 'skipped' (no invoice for zero-fee members).
   - Idempotency: `get_posts()` with `post_type => 'rondo_invoice'`, `post_status => any`, `suppress_filters => true`, `meta_query` for `person = $person_id` AND `_invoice_season = $season` AND `invoice_type = 'membership'`. If exists, return 'skipped'.
   - Create invoice: `wp_insert_post()` with `post_type => 'rondo_invoice'`, `post_title => $invoice_number` (from `InvoiceNumbering::generate_next()`), `post_status => 'rondo_draft'`, `post_author => 0`.
   - If `is_wp_error`, return 'error'.
   - Set ACF fields: `invoice_number`, `person` (person_id), `status` ('concept'), `invoice_type` ('membership'), `total_amount` ($fee_data['final_fee']).
   - Set line_items: single item with `discipline_case => null`, `description => 'Contributie ' . $season`, `amount => $fee_data['final_fee']`.
   - Store season meta: `update_post_meta( $post_id, '_invoice_season', $season )`.
   - Generate token: `PublicPaymentPage::generate_token( $post_id )`.
   - Return 'created'.

6. `public static function get_job_status(): array` — reads option, returns sanitized status (without person_ids array to keep response small).
