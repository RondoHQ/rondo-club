Extend `write_installment_meta()` in `PublicPaymentPage` to also write `_installment_N_due_date` for each installment.

1. Add a private static method `calculate_installment_due_dates( string $plan, string $season ): array` that returns installment number => Y-m-d date mapping:
   - For `quarterly_3`: `[ 1 => '{start_year}-09-25', 2 => '{start_year}-11-25', 3 => '{end_year}-02-25' ]`
   - For `monthly_8`: `[ 1 => '{start_year}-09-25', 2 => '{start_year}-10-25', ..., 8 => '{end_year}-04-25' ]`
   - Where `$start_year` is the first 4 chars of `$season` (e.g. 2025) and `$end_year` is `$start_year + 1`
   - Return empty array for any unrecognized plan

2. Inside `write_installment_meta()`, derive the season and compute due dates:
   - The invoice has no ACF `season` field. Derive season from the invoice's `post_date` using `MembershipFees::get_season_key( get_post_field('post_date', $invoice_id) )`.
   - Instantiate `MembershipFees` locally: `$fees = new \Rondo\Fees\MembershipFees();`
   - Determine the plan string: if `$count === 3` then `'quarterly_3'`, if `$count === 8` then `'monthly_8'`.
   - Call `calculate_installment_due_dates( $plan, $season )` to get the date array.
   - Inside the existing for loop, after writing `_status`, add:
     ```php
     if ( isset( $due_dates[ $n ] ) ) {
         update_post_meta( $invoice_id, '_installment_' . $n . '_due_date', $due_dates[ $n ] );
     }
     ```

3. The method signature stays the same: `write_installment_meta( int $invoice_id, int $count, float $total, float $admin_fee )`. No callers change.

Important: Keep the existing amount and status logic exactly as-is. Only ADD the due date calculation and writing.
