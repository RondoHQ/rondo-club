**Step 2: Create InvoicePdfGenerator class**

Create `includes/class-invoice-pdf-generator.php` in the `Rondo\Finance` namespace (same as InvoiceNumbering).

The class has one static public method: `generate( int $invoice_id ): string|WP_Error`

**Implementation details:**

1. **Validate invoice:** Get the invoice post, verify it's `rondo_invoice` post type. Return WP_Error if not found.

2. **Gather invoice data:**
   - Invoice fields via `get_field()`: invoice_number, person (post ID), total_amount, status, line_items (repeater), sent_date, due_date
   - If sent_date is empty, use current date as invoice date (for draft preview)
   - If due_date is empty, calculate from invoice date + FinanceConfig payment term days

3. **Gather person data:**
   - Get person post from the person field ID
   - Name: `get_field('first_name')`, `get_field('infix')`, `get_field('last_name')` - combine with array_filter + implode
   - Address: `get_field('addresses', $person_id)` - this is a repeater. Take the first address entry. Each entry has sub-fields: `address_label`, `street`, `city`. Format as: street on line 1, city on line 2.
   - Email: `get_field('contact_info', $person_id)` - this is a repeater of contact methods. Loop through entries, find one where `type` is 'email' (or 'Email'), take its `value`. Use the first email found.
   - Return WP_Error if person not found.

4. **Gather club/finance settings** via FinanceConfig (note: FinanceConfig is in `Rondo\Config` namespace, not `Rondo\Finance` — add `use Rondo\Config\FinanceConfig;` at the top of the class file). Use `new FinanceConfig()`:
   - `get_org_name()` - organization name for header
   - `get_org_address()` - organization address for header (multi-line, use nl2br)
   - `get_contact_email()` - contact email for header
   - `get_iban()` - bank account number
   - `get_payment_clause()` - payment clause text (multi-line, use nl2br)

5. **Get club logo:**
   - Use the Rondo logo at `public/icons/rondo-logo.png` (absolute file path via `get_template_directory() . '/public/icons/rondo-logo.png'`)
   - Only include if file_exists

6. **Build HTML template** as a PHP string. Use inline CSS for mPDF compatibility (mPDF supports a subset of CSS). The template layout:

   ```
   │ [Logo]  Club Name                           │

   │ Aan:                                        │
   │ Member Name                                 │
   │ Street                                      │
   │ City                                        │
   │ member@email.com                            │
   │                                             │
   ├─────────────────────────────────────────────┤
   │ Omschrijving              Sanctie    Bedrag │
   │ ─────────────────────────────────────────── │
   │ Match description 1       Sanction    €X.XX │
   │ Match description 2       Sanction    €X.XX │
   │ ─────────────────────────────────────────── │
   │                           Totaal      €X.XX │
   │                                             │
   ├─────────────────────────────────────────────┤
   │ Betaalgegevens                              │
   │ IBAN: NL12 RABO 0123 4567 89               │
   │ t.n.v. Club Name                           │
   │                                             │
   │ Payment clause text                         │

   ```

   **Date formatting:** Use Dutch date format. Create a helper method `format_dutch_date( string $ymd_date ): string` that converts ACF Ymd date format (e.g., "20260216") to Dutch format (e.g., "16 februari 2026"). Use a static array of Dutch month names.

   **Currency formatting:** Format amounts as `number_format($amount, 2, ',', '.')` with euro sign prefix.

   **Line items table:** For each line_item in the invoice, show:
   - Column 1 (Omschrijving): The item description. If a discipline_case is linked, use `get_field('match_description', $case_id)` as primary, fall back to the stored description field.
   - Column 2 (Sanctie): If discipline_case linked, use `get_field('sanction_description', $case_id)`. Otherwise empty.
   - Column 3 (Bedrag): The item amount formatted as currency.
   - Total row at bottom with sum.

   **HTML/CSS styling:**
   - Use `font-family: DejaVu Sans` (mPDF built-in, supports UTF-8/Euro sign)
   - A4 format, portrait orientation
   - Margins: 20mm all sides
   - Header section with club logo (50px height), club name in bold, address, email
   - "FACTUUR" as h1 (24px, bold, color #0891b2 electric-cyan brand color)
   - Clean table with bottom border on header row and total row
   - Table widths: 50% description, 30% sanction, 20% amount (right-aligned)
   - Payment section with light gray (#f8f8f8) background
   - Font size: 10pt body, 12pt for labels

7. **Generate PDF with mPDF:**

**Step 1: Add REST endpoint for PDF generation**

```php
// Generate PDF for invoice
register_rest_route(
    'rondo/v1',
    '/invoices/(?P<id>\d+)/generate-pdf',
    [
        [
            'methods'             => \WP_REST_Server::CREATABLE,
            'callback'            => [ $this, 'generate_pdf' ],
            'permission_callback' => [ $this, 'check_financieel_permission' ],
            'args'                => [
                'id' => [
                    'validate_callback' => function ( $param ) {
                        return is_numeric( $param );
                    },
                ],
            ],
        ],
    ]
);
```

Add the `generate_pdf` callback method:

```php
public function generate_pdf( $request ) {
    $invoice_id = (int) $request->get_param( 'id' );

    // Validate invoice exists
    $invoice = get_post( $invoice_id );
    if ( ! $invoice || $invoice->post_type !== 'rondo_invoice' ) {
        return new \WP_Error(
            'rest_not_found',
            __( 'Invoice not found.', 'rondo' ),
            [ 'status' => 404 ]
        );
    }

    // Generate PDF
    $result = InvoicePdfGenerator::generate( $invoice_id );

    if ( is_wp_error( $result ) ) {
        return $result;
    }

    // Return updated invoice detail (now includes pdf_path)
    $invoice = get_post( $invoice_id );
    return rest_ensure_response( $this->format_invoice_detail( $invoice ) );
}
```

Add the `use` statement at the top of the file (after existing `use` statements):


Add the `download_pdf` callback:

```php
public function download_pdf( $request ) {
    $invoice_id = (int) $request->get_param( 'id' );

    $invoice = get_post( $invoice_id );
    if ( ! $invoice || $invoice->post_type !== 'rondo_invoice' ) {
        return new \WP_Error(
            'rest_not_found',
            __( 'Invoice not found.', 'rondo' ),
            [ 'status' => 404 ]
        );
    }

    $pdf_path = get_field( 'pdf_path', $invoice_id );
    if ( empty( $pdf_path ) ) {
        return new \WP_Error(
            'rest_no_pdf',
            __( 'No PDF generated for this invoice.', 'rondo' ),
            [ 'status' => 404 ]
        );
    }

    $upload_dir = wp_upload_dir();
    $full_path  = $upload_dir['basedir'] . '/' . $pdf_path;

    if ( ! file_exists( $full_path ) ) {
        return new \WP_Error(
            'rest_file_not_found',
            __( 'PDF file not found on disk.', 'rondo' ),
            [ 'status' => 404 ]
        );
    }

    // Get invoice number for filename
    $invoice_number = get_field( 'invoice_number', $invoice_id );
    $filename = 'factuur-' . $invoice_number . '.pdf';

    // Serve PDF file directly
    header( 'Content-Type: application/pdf' );
    header( 'Content-Disposition: inline; filename="' . $filename . '"' );
    header( 'Content-Length: ' . filesize( $full_path ) );
    readfile( $full_path );
    exit;
}
```
