**1. Create `src/utils/csvExport.js`** with three exported functions:

- `escapeCell(value)`: Returns empty string for null/undefined. Converts value to string. If string contains `;`, `"`, `\n`, or `\r`, wraps in double-quotes and escapes existing quotes by doubling them (RFC 4180).
- `buildCsv(rows)`: Takes a 2D array (array of row-arrays), maps each cell through `escapeCell`, joins cells with `;` (semicolon — Dutch Excel convention), joins rows with `\r\n`.
- `downloadCsv(csvString, filename)`: Prepends UTF-8 BOM (`\uFEFF`) to csvString, creates a Blob with type `text/csv;charset=utf-8;`, creates an object URL, creates a temporary `<a>` element with `download` attribute set to `filename`, clicks it, removes element, revokes object URL.
