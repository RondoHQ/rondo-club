# Security Policy

## Supported versions

Rondo Club is actively maintained on the `main` branch. Security fixes are expected to land in the latest supported release line first.

| Version | Supported |
| --- | --- |
| Latest release | ✅ |
| Older releases | ❌ |
| Unreleased feature branches | ❌ |

## Reporting a vulnerability

Please **do not open a public GitHub issue** for security problems.

Instead, report vulnerabilities privately to:

- **GitHub Private Vulnerability Reporting**, if enabled for this repository
- or the maintainers via the organization security/contact channel

Include as much detail as possible:

- affected area or endpoint
- reproduction steps or proof of concept
- impact assessment
- suggested mitigation, if known

## Response expectations

Maintainers aim to:

- acknowledge a report within **3 business days**
- provide an initial assessment within **7 business days**
- coordinate disclosure after a fix is available

## Disclosure

Please give maintainers reasonable time to investigate and ship a fix before any public disclosure.
